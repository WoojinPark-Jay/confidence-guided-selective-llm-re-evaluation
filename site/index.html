RESEARCH CONTRIBUTIONS

Selective re-evaluation, measured end to end

The study asks when an LLM should reconsider a classifier's prediction, and whether its corrections outweigh the errors it introduces.

01 A selective two-phase pipeline
A compact classifier retains high-confidence predictions; only calibration-defined low-confidence posts reach the LLM.
02 A fixed, reproducible routing policy
Temperature scaling and a risk-bound criterion select a maximum-coverage threshold from a prespecified grid, before held-out evaluation.
03 Separate audits of routing and correction
Error capture measures what the router finds. Corrected and introduced errors measure what the re-evaluator changes. The main comparison crosses two LLMs with three protocols on matched routed inputs.
04 Task-adapted SELF-DISCOVER
An emotion-oriented module bank, a reusable model-generated plan, and researcher-authored evidence checks are evaluated on exploratory sets and a separate fixed-protocol 9,000-post set.

Abstract

Large language models can reconsider uncertain classifications, but re-evaluating every input increases generation workload and can introduce new errors. We study confidence-guided selective re-evaluation for three-class emotion classification in social media. A temperature-scaled DistilBERT classifier retains high-confidence predictions and routes the remaining posts to Llama 2 or Llama 3 using Direct, chain-of-thought (CoT), or task-adapted SELF-DISCOVER prompts.

On the exploratory 12,000-post Reddit evaluation, Llama 3 SELF-DISCOVER improves accuracy from 96.92% to 97.20% while re-evaluating 1.82% of posts. On a separate, fixed-protocol evaluation of 9,000 posts, it produces 17 net corrections while routing 1.23%, with a significant improvement over Phase 1 under the specified Holm adjustment. SELF-DISCOVER has the highest observed accuracy across the evaluated sets, but its differences from Direct and CoT are not statistically resolved on Reddit. The results describe a proxy-label classification task, not clinical diagnosis.

01 / METHOD

Confidence first, re-evaluation when needed

Confidence-based routing

Phase 1 predicts Depression, Neutral, or Happy. Temperature scaling adjusts the model's confidence, and a threshold determines which predictions are retained. The selected threshold is τ = 0.70: 11,807 of 12,000 calibration posts are accepted, with 1.940% empirical error and a 2.162% one-sided Clopper–Pearson upper bound.

The lowest candidate in the prespecified 0.70–1.00 grid already satisfies the 5% risk budget, so the grid boundary determines the operating point. Temperature fitting and threshold selection use the same calibration partition. The pointwise bound is not a simultaneous post-selection guarantee and does not guarantee the same risk under distribution shift.

Calibration diagnostics Reliability, NLL, Brier score, and ECE

Selective LLM re-evaluation

Direct uses one generation call. CoT uses five dialogue turns, including acknowledgment and text-response turns. SELF-DISCOVER constructs a task-level plan from the class policy and 18 researcher-authored reasoning modules, then reuses that plan for a fresh evaluation of each routed post. Plan construction does not receive evaluation posts or their reference labels.

The protocols differ in label visibility, call structure, and generation budget; the comparison is between complete configurations rather than an isolated test of reasoning components. If the final label cannot be parsed, the Phase 1 prediction is retained.

The four procedures in the paper

The runtime order is 1 → 2 → 4 → 3 for SELF-DISCOVER; numbering follows the paper. Algorithms 1 and 3 are not part of per-post LLM reasoning.

Algorithm 1Calibrated confidence-guided routingCalibration only
Accessible text equivalent

Input Dval, Dcal, classifier fθ; risk budget α, confidence level 1 − δ, grid T, minimum count mmin.

Output Temperature T* and threshold τ*.

  1. Select the best checkpoint using Dval.
  2. Fit T* on Dcal by minimizing negative log-likelihood.
  3. Compute calibrated confidences ci on Dcal.
  4. For each threshold τ in the prespecified grid:
  5. Form accepted set A(τ) and routed set R(τ).
  6. Compute coverage, routing rate, and the upper risk bound.
  7. Retain candidates with upper risk bound ≤ α and |A(τ)| ≥ mmin.
  8. If no candidate remains, flag infeasibility; a fallback is not risk-feasible.
  9. Choose a retained threshold with maximum coverage.
  10. Fix T* and τ* before held-out testing.
Algorithm 2Two-phase inference with fixed calibrated routing policyOne post
Accessible text equivalent

Input Post x; classifier fθ; fixed T* and τ*; Phase 2 model and prompting protocol g.

Output Final label and parsing status.

  1. Obtain the Phase 1 input x(1) from post record x.
  2. Compute logits z = fθ(x(1)) and calibrated probabilities qk(T*).
  3. Set Phase 1 label y1 = arg maxk qk(T*) and confidence c = maxk qk(T*).
  4. If c ≥ τ*: return y1. No Phase 2 call.
  5. Otherwise, retrieve the minimally sanitized original text x(2).
  6. Generate a response with g using its prescribed inputs.
  7. Parse exactly one label from {Depression, Neutral, Happy}.
  8. If parsing fails, retain y1 and record the failure.
  9. Return the parsed label or recorded fallback.
Algorithm 3Audited end-to-end evaluation of routed predictionsAll evaluation posts
Accessible text equivalent

Input Reference labels yi, Phase 1 predictions, route indicators ri, and parsed Phase 2 labels.

Output Corrected errors C, introduced errors I, net corrections C − I, and full-set metrics.

  1. For each example, use Phase 2 only if it was routed and parsing succeeded; otherwise use Phase 1.
  2. Count C: routed examples where Phase 1 was wrong and the final prediction is correct.
  3. Count I: routed examples where Phase 1 was correct and the final prediction is wrong.
  4. Report C, I, and C − I.
  5. Recompute end-to-end metrics over all examples, including accepted posts.
Algorithm 4Final task-level SELF-DISCOVER re-evaluationSaved plan + routed posts
Accessible text equivalent

Input Model g; researcher-authored task, policy, modules, execution guidance; routed posts.

Output Stored response, parsing status, and final prediction for each routed post.

  1. If a retained plan for g exists: load it and skip discovery.
  2. Otherwise, give g task materials only; no post text or labels.
  3. Have g SELECT relevant modules and ADAPT them to the task.
  4. Have g IMPLEMENT the procedure; store it as the plan.
  5. For each routed post, execute the plan on its original text without the Phase 1 label.
  6. Request source quotes, three-label evidence, and a counterfactual check.
  7. Parse the final label; retain Phase 1 if parsing fails.
  8. Store the response, parsed status, and final prediction.

Selected operating point: T* = 1.480195; τ* = 0.70. The calibration risk constraint was non-binding within the prespecified grid. Source: manuscript Section V and the released notebooks.

05 / EVALUATION

Results across the evaluated sets

The main Reddit and synthetic Mixed Emotion sets were used during prompt development and are exploratory evaluations. The additional 9,000-post run keeps model weights, temperature, threshold, prompts, and the saved plan fixed.

What changes after re-evaluation?

In the fixed 9,000-post evaluation, only 111 posts reached the LLM. SELF-DISCOVER corrected 30 errors but changed 13 correct predictions to errors: 17 more correct predictions overall, or +0.19 percentage points. The other 8,889 predictions stayed with Phase 1.

On the additional evaluation, the exact McNemar p-value for SELF-DISCOVER versus Phase 1 is 0.0137 (Holm-adjusted p = 0.0412 within the three-test family). Direct and CoT each yield 13 net corrections. Their accuracy differences from SELF-DISCOVER are not significant (both Holm-adjusted p = 0.9614).

Recorded model-generation time on an NVIDIA L4 is 54.9 s for Direct, 3,116.4 s for CoT, and 2,568.5 s for SELF-DISCOVER. Thus, Direct produces four fewer net corrections than SELF-DISCOVER at about 2.1% of its recorded generation time. These measurements cover generation, not total pipeline runtime.

KEY FINDINGS

What the results establish

  1. Confidence routing concentrates errors.

    In the main Reddit evaluation, 1.82% of posts contain 26.49% of Phase 1 errors. Their error rate is 44.95%, compared with 3.08% overall. Routing identifies a difficult subset, but leaves errors outside it.

    Routing analysis →

  2. Selective re-evaluation produces a modest net gain.

    On the fixed-protocol same-source 9,000-post set, SELF-DISCOVER raises accuracy from 97.58% to 97.77%, with 17 net corrections. The Phase 1 comparison is significant under the specified three-test Holm adjustment (p = 0.0412).

    Paired comparisons →

  3. Protocol choice is an accuracy–workload tradeoff.

    Direct yields 13 net corrections versus 17 for SELF-DISCOVER at about 2.1% of its recorded generation time. Their accuracy difference is not significant on the additional set; the highest observed accuracy is not evidence of universal superiority.

These findings concern community-derived proxy labels. The main Reddit and Mixed Emotion evaluations informed prompt development; the additional evaluation used a fixed protocol. Clinical validity and cross-platform generalization are not established.

06 / DATA

Data and annotation

The Reddit labels are community-derived proxies for Depression, Neutral, and Happy. The 300-example synthetic Mixed Emotion set tests mixed or shifting affect under a shared classification policy. It was generated using GPT-5 via Codex and researcher-authored scenario and label constraints, and also informed prompt development.

Two researchers uninvolved in data generation or Phase 2 prompt development independently annotated all 300 examples without seeing targets, scenario metadata, model outputs, or each other's responses. They agreed on 277 examples (92.33%; unweighted Cohen's κ = 0.8847). Agreement with the original targets was 96.00% and 96.33%. A third researcher checked completeness, record alignment, and statistics. No adjudication or post-audit relabeling was performed.

Synthetic data and anonymized annotations · Annotation statistics

Scope

Subreddit-derived labels can carry topic and lexical biases. The annotation audit supports consistency with the shared policy, not clinical validity or generalization to real-world populations. The results do not establish a universal advantage of SELF-DISCOVER, the isolated contribution of its planning and evidence checks, or generalization to newer models and other platforms.
