# 프로젝트 페이지 3개 관점 개선 기록

2026-10-25. 시각 디자인, UI 동작, 연구 내용 전달을 서로 다른 에이전트가 검토하고 수정한 뒤 통합했다. 논문 결과나 실험은 변경하지 않았다.

## 1. 시각 디자인

- 기존: 본문과 근거 자료의 폭 및 구역별 여백이 일관되지 않았다.
- 변경: 본문은 760px, 표·그림 중심 영역은 960px 기준으로 정리했다. 제목, 표, 캡션, 구역 간격을 축소하고 중복 스타일 일부를 통합했다.
- 유지: 흰 배경, Times 계열 서체, 절제된 버건디 링크, 얇은 테두리 튜토리얼 링크, 원본 논문 그림.
- 모바일 표·알고리즘은 영역 내부 스크롤을 사용하며 컨트롤과 혼동행렬 라벨의 배치를 보완했다.

## 2. UI 동작

- 기존: 혼동행렬과 프로토콜 결과의 데이터셋 선택이 서로 독립적이었다.
- 변경: 양방향으로 동기화한다. 선택 가능한 Phase 2 모델은 공개 결과에서 결정하며, 유효한 모델 선택은 유지한다.
- 혼동행렬은 Llama 3 SELF-DISCOVER 전후 비교이며, 프로토콜 결과에서 Llama 2를 선택해도 다른 모델의 행렬처럼 표시하지 않는다.
- 알고리즘 링크는 해당 패널을 펼친다. 초기 URL, 재클릭, 해시 이동을 처리한다. 일반 진입 시 Algorithm 1만 열린 기본 상태는 유지한다.
- 프롬프트 탭별 문서 선택을 기억하며 키보드 탐색도 유지한다.

## 3. 내용과 읽는 순서

- 기존: 결과에 도달하기 전에 알고리즘과 프롬프트 상세 자료를 지나야 했다.
- 변경: Method → Results → Findings → Algorithms → Cases → Prompts 순서로 재배치했다.
- Phase 1 모델 선택, 보정과 라우팅, Phase 2 재평가, 동일 표본의 baseline/final 비교를 명확히 구분했다.
- 3-seed 평균과 최종 seed-42 성능을 혼동하지 않도록 설명을 유지했다.
- Mixed Emotion 생성 설명을 manuscript v3의 GPT-5 via Codex 및 버전 관리된 시나리오 템플릿 스크립트 설명과 맞췄다.
- 탐색적 평가, 추가 평가의 same-source 범위, 비임상적 용도와 통계적 비교 한계는 유지했다.

## 검증

- Python 테스트 14개 통과: 공개 결과, 행렬, 예시, 프롬프트, 알고리즘 및 빌드 자산 검사.
- Node 테스트 12개 통과: 보정 계산 7개 및 신규 UI 회귀 테스트 5개.
- 브라우저에서 데이터셋 양방향 동기화, Llama 2 선택과 행렬 범위 분리, 알고리즘 링크 펼침을 확인했다.
- 데스크톱 초기 화면을 시각적으로 확인했다. 모바일 폭에서 문서 가로 넘침이 없음을 DOM으로 확인했다.
- 브라우저의 스크롤 이후 캡처가 일부 잘려 모바일 전체 시각 검수를 완료했다고 주장하지 않는다. 화면 크기별 추가 시각 검수 여지가 남는다.
- GitHub Pages CI에도 신규 UI 회귀 테스트를 추가했다.

공개 페이지 개선만 포함한다. 비공개 원고 PDF, Reddit 원문, 개인 식별자는 추가하지 않았다.
