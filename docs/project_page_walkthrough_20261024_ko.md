# 프로젝트 페이지 보강: 알고리즘과 실제 실행 사례

## 최종 정보 우선순위 및 수식 표시 보강

- 앞부분에 원고의 네 가지 Contributions와 고정 9,000건 평가의 핵심 발견(111건 재평가, 30건 교정, 13건 새 오류, 순교정 17건)을 추가했다.
- 뒤쪽 Findings는 오류 집중, 전체 성능 순개선, 정확도와 생성 부하의 선택이라는 세 결과로 정리했다. 탐색적 평가와 고정 평가, 프로토콜 간 비유의성, 프록시 라벨의 범위는 유지했다.
- 호출 횟수·Phase 1 라벨 공개 여부 표는 주 내용에서 내려 `Protocol settings and comparison conditions` 펼침 항목으로 이동했다.
- 앞선 텍스트 중심 알고리즘 표현은 원고 PDF의 Algorithm 1–4 실제 이미지로 대체했다. 9쪽의 1–3번과 10쪽의 4번만 300dpi로 추출했고, 첨자·합 기호·수식·들여쓰기·원래 줄 번호를 보존했다.
- 이미지 네 개는 직접 확인했다. PC에서는 최대 780px로 표시하고, 모바일에서는 수식을 너무 작게 축소하지 않도록 영역 내부 가로 스크롤과 원본 이미지 링크를 제공한다. 검색/접근성용 텍스트 등가 설명도 접힌 항목으로 남겼다.
- 원본 전체 PDF는 공개하지 않았다. 추출 스크립트 `scripts/render_site_algorithms.py`에 원본 SHA-256, 페이지, 자르기 좌표를 기록했다.
- 기존 합성 사례 데이터 및 실제 모델 응답은 변경하지 않았다.


## 후속 구성 재검토

초기 보강본은 일반적인 실행 순서 요약과 긴 단일 열 데모에 머물렀다. 피드백 후 다음과 같이 다시 구성했다.

- 최종 원고 Section V의 실제 Algorithm 1–4를 읽고, 네 제목과 논리 절차를 웹용 텍스트로 옮겼다. 입력·출력·행 번호를 갖춘 알고리즘 형태로 표시한다. 웹 표기는 가독성을 위한 재구성이며 원문 이미지나 동일한 줄 번호를 주장하지 않는다.
- Algorithm 1은 calibration 정책 선택, 2는 고정 정책 추론, 3은 전체 평가, 4는 SELF-DISCOVER 실행이다. 상단 흐름에서는 실제 실행 관계인 1 → 2 → 4 → 3을 보여주고 해당 항목으로 연결한다.
- Algorithm 2는 기본으로 펼치고 다른 세부 절차는 접는다. 보정 그래프도 별도 펼침 항목으로 두어 세부자료가 읽는 흐름을 끊지 않도록 했다.
- 사례 선택은 숨겨진 드롭다운 대신 네 가지 유형을 바로 볼 수 있는 라디오 선택으로 바꿨다.
- 사례 상단에 Phase 1 → 라우팅 판단 → 최종 예측을 배치하고, 하단에는 원문과 모델 근거를 좌우로 나란히 배치했다. 모바일에서는 세로로 전환한다.
- 원문의 마지막 문장 강조는 편집상 강조이며 모델의 기여도/중요도 분석 결과가 아니라고 표시했다. 모델 응답 전문과 원본 JSON 링크를 유지했다.
- 섹션 제목, 폭, 구분선, 자료의 펼침 단계를 통일했다. 논문 수치, 예측 라벨, 모델 응답은 변경하지 않았다.


## 변경 내용

### 가독성 후속 정리

- bounded-history-agreement 페이지의 연구 질문과 정보 위계가 명확한 점을 참고했다. 디자인을 복제하지 않고 기존 아키텍처 그림과 서체를 유지했다.
- 그림 앞에 연구 질문을 한 문장으로 제시하고 캡션을 짧게 줄였다. 고정 프로토콜 9,000건 평가의 재평가 비율 1.23%, 순수정 +17건, 최종 정확도 97.77%를 그림 바로 아래에 나눠 표시한다.
- Phase 1 대비 개선과 Direct/CoT 대비 비유의를 같은 요약 영역에 유지했다. 탐색적 평가 여부와 비임상 라벨 설명은 기여 바로 아래에 남겼다.
- 기여 설명을 짧은 제목/설명으로 줄이고 데스크톱 2열, 모바일 1열로 정리했다. 중복된 기존 MAIN FINDING 문단은 요약 영역으로 통합했다.
- 밝은 파란 링크를 버건디로 바꾸고 탭 선택, 펼침, 키보드 포커스에도 적용했다. 그래프 안의 데이터 색상은 변경하지 않았다.

- 두 저자의 고려대학교 소속 확인 후, 기존 bounded-history-agreement 페이지와 같은 고려대학교 로고를 상단에 배치했다. 학과나 추가 소속은 추정하지 않았다.
- 전체 아키텍처 그림은 유지했다. Algorithm 항목에서 사전 준비(보정, 임계값 선택, 모델별 plan 저장)와 게시글별 실행(분류, 라우팅, 재평가, 라벨 추출)을 분리했다.
- confidence 0.70 이상이면 Phase 1 예측을 유지하고, 미만이면 원문을 재평가하는 분기를 표시했다. 라벨 추출 실패 시 Phase 1으로 돌아가는 규칙과 접을 수 있는 의사코드를 추가했다.
- Case walkthrough에서 입력 원문, Phase 1 라벨/확신도, 라우팅 여부, 최종 라벨, 평가용 정답을 한 흐름으로 표시한다. 선택 메뉴로 네 사례를 전환하고 실제 모델 응답 전문을 펼쳐 볼 수 있다.

## Calibration 인터랙티브 튜토리얼 추가 (초기 버전)

### Key findings 링크 수정

후속 검수: 공개 페이지의 세 링크는 서로 다른 해시로 이동했고 도착 요소는 화면 상단 약 24px에 위치했다. 그러나 통계 비교와 생성 시간 근거가 약 150px 간격으로 붙어 있어 같은 화면으로 느껴질 수 있었다. 따라서 현재 버전은 이동 링크를 제거하고 각 finding 아래에서 별도 근거를 펼치는 방식으로 변경했다. 첫 항목은 라우팅 그림, 둘째는 Holm 비교표, 셋째는 생성 시간/순수정 표가 열린다. 기존 근거 위치 ID는 직접 링크 호환을 위해 유지한다. 아래 목록은 최초 수정 기록이다.

- 세 근거 링크가 모두 `#results`로 이동하던 문제를 수정했다.
- Routing analysis는 라우팅 그림, Paired comparisons는 McNemar/Holm 비교 설명, Generation workload는 기록된 생성 시간 설명으로 각각 직접 이동한다.
- 통계 및 생성 시간 설명에 소제목을 추가하고, 도착 위치에 얇은 테두리를 표시한다. 각 링크의 고유 목적지 존재 여부를 자동 검사한다.

- 메인 페이지 상단과 calibration 설명에 별도 `tutorial.html` 링크를 추가했다. 메인 연구 소개가 길어지지 않도록 튜토리얼을 분리했다.
- 온도 T 슬라이더, 재생/정지, 초기화, 교육용 NLL 최소값 버튼을 제공한다. 클래스 확률, NLL/Brier/ECE 값과 곡선, reliability diagram, ECE bin별 계산이 함께 갱신된다.
- softmax, NLL, multiclass Brier, ECE 수식을 MathML로 표시하고 각 지표의 의미와 차이를 설명한다.
- 교육용으로 만든 12개 logit 벡터, 3개 클래스, 5개 ECE bin을 사용한다. 실제 논문 예측이나 추가 실험 결과가 아니다. 논문 진단은 15개 bin을 사용한다는 차이도 명시했다.
- 양의 온도에서는 예측 순위와 정확도(9/12)가 유지된다. NLL 최소값이 다른 두 지표의 최소값을 보장하지 않으며, ECE는 bin 경계 이동 때문에 불연속적으로 변할 수 있다.
- 메인 제목, 섹션 간격, SELF-DISCOVER 그림과 알고리즘 표시 폭, 사례 결과 글자 크기를 소폭 줄였다. Algorithm 1만 기본으로 열리고 2~4는 닫힌 상태를 유지한다.
- 계산 코어에 Node 단위 테스트 3개를 추가하고 배포 검사에도 포함했다. 확률 합, 양의 온도에서 예측 불변, Brier 정의, ECE 집계 및 잘못된 온도 입력을 검증한다.
- 튜토리얼도 배포 시 CSS/JS 파일명을 해시화한다. 로컬 HTML은 외부 API 없이 동작한다. 기존 논문, 실험 수치, 모델 응답은 변경하지 않았다.

## 튜토리얼 보강 (현재 버전)

- 튜토리얼 첫 화면 제목을 'Temperature Scaling & Calibration'으로 변경하고, 학습 주제(확률, 보정 지표, 온도 선택)를 번호와 함께 제시했다. 기존 'Confidence is not accuracy.' 문구는 제목에서 제거했다.
- 프로젝트 상단과 Method의 튜토리얼 진입 링크를 강조했다. 후속 디자인 의견에 따라 버건디 채움 버튼은 제거하고, 기존 링크 크기의 글씨와 얇은 사각 테두리만 유지했다. 상단은 'Tutorial', 본문은 'Calibration tutorial'로 줄였으며 hover 및 키보드 focus 상태를 제공한다.

- 12개는 개별 손실을 설명하는 데 유용하지만 bin별 정확도 추정에는 너무 희소할 수 있어, 기본값을 600개 가상 예측과 10개 bin으로 변경했다. 12/60/600개 및 5/10/15개 bin을 선택할 수 있다. 12개에서는 15개 bin을 비활성화한다.
- 600개라는 수가 통계적 충분성을 보장하지는 않는다. 사용 중인 bin 수, 빈 bin 여부, 최소 비어 있지 않은 bin 크기를 표시하고 10개 미만이면 희소성을 알린다. 이 경고 기준은 교육용 안내이며 검정 기준이 아니다.
- 12개는 기존 수작업 예제, 60개는 600개 시뮬레이션의 앞부분이다. 서로 다른 표본의 ECE 차이를 실험적 개선으로 해석하지 않도록 명시했다.
- 시뮬레이션은 seed 20261024인 고정 PRNG로 logit 3개를 [0, 5)에서 추출하고, softmax(z/1.8)에서 정답을 표집한다. T=1의 과신이 생성 규칙에 포함된 교육 자료다. 실제 텍스트, 실제 모델 추론, 추가 논문 실험이 아니다.
- 동일 폭 ECE와 동일 개수 adaptive ECE 전환을 추가했다. 후자는 최대 확률로 정렬한 후 비슷한 크기로 나눈 bin의 가중 절대 오차다. 모든 클래스 확률을 사용하는 ACE와 구분한다. 동률은 입력 순으로 나누며, bin 표에 관측 범위를 표시한다.
- 온도 네 상태(0.50, 1.00, NLL 최소, 3.00)를 바로 선택하고, 현재 상태 해설을 제공한다. T=1 기준 가장 확신한 오답, 가장 확신한 정답, 가장 확신이 낮은 정답을 개별 사례로 고를 수 있다.
- 최소 NLL 위치를 곡선에 표시하고, 251개 온도 격자(0.50~3.00, 간격 0.01)를 비교하는 절차와 네 상태의 수치 표를 추가했다. 데이터와 최적화 범위가 제한된 표본 내 시연임을 명시했다.
- 실제 공개 노트북은 SciPy minimize_scalar(method="bounded"), 범위 0.05~10.0, calibration NLL을 사용한다. 확률을 1e-12에서 clip하는 구현도 확인했다. 실제 보고 T=1.480195와 예제의 최적 T를 구분했다.
- 공개 노트북에는 동일 폭 ECE뿐 아니라 15-bin adaptive ECE도 이미 있다. 초기 설명의 누락을 바로잡고 구현 링크를 추가했다.
- 수식의 축소된 글자와 간격은 유지했다. 긴 생성 방식·최적화 설명은 펼침 영역으로 제공한다.
- 참고: Guo et al. (2017), https://proceedings.mlr.press/v70/guo17a.html ; Nixon et al. (2019), https://openaccess.thecvf.com/content_CVPRW_2019/html/Uncertainty_and_Robustness_in_Deep_Visual_Learning/Nixon_Measuring_Calibration_in_Deep_Learning_CVPRW_2019_paper.html .
- 검증: 계산 테스트 7개(수식, 표본 재현성, 동일 개수 분할, 동률 처리, 극단 점수 NLL 등), 웹 배포 자산 검사, 12/60/600개와 두 bin 방식의 브라우저 전환을 확인했다. 논문이나 보고된 결과는 변경하지 않았다.

## 2026-10-25: Phase 1 모델 선택과 최종 개선 연결

- 이전: Method가 calibration부터 시작해 세 분류기의 비교와 DistilBERT 선택 근거가 드러나지 않았다. 최종 혼동행렬만으로는 Phase 1 대비 변화를 직접 읽기 어려웠다.
- 변경: Method 앞부분에 DistilBERT / Mistral 7B / Llama 2 7B의 정확도, macro F1, 처리량 표를 추가했다. 원고 Table 2와 대조했으며 정확도는 각각 96.88 / 95.36 / 95.17%, 처리량은 4,959.5 / 51.7 / 55.5 posts/s다.
- 비교 조건: DistilBERT는 full fine-tuning, 나머지는 frozen-backbone linear head다. 동일 12,000건 시험셋과 seed 42/43/44, 모델별 4-trial 검색을 사용한 구성 비교이며, 완전 미세조정한 7B 모델의 성능 비교로 표현하지 않았다. 처리량의 반복 측정은 학습 시드와 별개다.
- 기준선 구분: 모델 선택용 3-seed 평균 96.88%와 downstream seed-42 실행의 Reddit 정확도 96.92%는 별개로 명시했다. 모델 선택 평균에서 최종 성능을 빼서 개선량을 만들지 않았다.
- Results에 데이터셋 선택형 전후 혼동행렬을 추가했다. 같은 게시물의 Phase 1 DistilBERT 예측과 최종 Llama 3 SELF-DISCOVER 예측을 나란히 표시한다. 모바일에서는 위아래로 배치한다.
