# Contributing

This repository is a paper-linked reproducibility package. Changes that alter a reported result must include:

1. the exact input and model hashes;
2. an updated run manifest;
3. text-free row-aligned predictions;
4. regenerated metrics and paired statistics;
5. updated release checksums;
6. passing release validation and tests.

Do not commit raw Reddit text, credentials, model weights, runtime caches, or exploratory outputs under final filenames.
